# しんたろうジャンケン（オンライン版）

オープン5人・プライベート5〜8人のオンライン対戦、オープンマッチ、合言葉つきプライベートルーム、ホストによるCPU補充、CPU単独対戦を収録しています。

## 起動

Node.js 20以上を用意して、フォルダ内で以下を実行してください。

```bash
npm install
npm start
```

ブラウザで `http://localhost:3000` を開きます。同じWi-Fiのスマホから試す場合はPCのLAN内IPアドレスを指定してください（ファイアウォールの許可が必要な場合があります）。

## インターネット公開

Render等のNode.jsホスティングにこのフォルダをデプロイします。ビルドコマンド `npm install`、起動コマンド `npm start`、環境変数 `PORT` はホスティング側の自動設定を使用。HTTPSの公開URLを5人で共有してください。無料枠などではスリープ・再起動により対戦が切れることがあります。

## モード

- オープン：5人集まったら自動開始。待機人数が5人未満の場合は開始しません。
- プライベート：ルーム名と4〜32文字の合言葉で入室。ホストはCPUを0〜7人追加でき、CPU込み合計5〜8人になったらホストの開始ボタンで始められます。
- CPU対戦：`/cpu.html` でローカルプレイ。サーバーに接続せず動きます。

## 注意点

試作版です。サーバー再起動でルームとスコアは消去されます。接続切断後の試合はCPUが引き継ぎますが、途中復帰はできません。合言葉はサーバーメモリ上に保持し、暗号化データベースなどは使用していません。公開運用での不正アクセス対策、レート制限、永続化、複数サーバー間同期は未実装です。公開URLの発行にはデプロイが必要です。
